# 🏥 SanaFlow AI

Aplicación web desarrollada con Streamlit e Inteligencia Artificial para automatizar la recepción y clasificación de mensajes de pacientes en consultorios médicos.

## Descripción
SanaFlow AI ayuda a los profesionales de la salud a transformar textos desorganizados o audios de pacientes en fichas clínicas estructuradas (Motivo, Síntomas, Prioridad) utilizando OpenAI.
